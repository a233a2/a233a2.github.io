CH32V307-TinyLLM：让单片机自己跑一个小 Transformer

在 CH32V307 上跑 TinyStories-260K：分词、前向、采样、解码全在 MCU 里，屏幕直接显示结果

2026-10-15
阅读时长: 4 分钟

项目想做啥

一直想试试"大模型能不能塞进单片机"。手里有块 CH32V307 开发板，屏幕是 1.14 寸的 ST7789V，就拿来做了。

目标很简单：在 PC 上打一句话，单片机自己算完，把结果直接显示在屏幕上。

硬件

  • 主控：CH32V307VCT6，RISC-V，256 KB Flash + 64 KB SRAM，我把它超到 144 MHz 用
  • 屏幕：ST7789V，135×240 IPS，1.14 寸，走 SPI2
  • 调试/串口：WCH-Link，USART1，115200
  • 字库：Fusion Pixel 12px，7364 个字形

模型用的是 Karpathy 的 TinyStories-260K，26 万参数，5 层 Transformer（dim=64，hidden=172），结构完整但非常小。量化成 Q8 之后是 278 KB —— Flash 根本放不下，SRAM 更不可能，所以权重只能放在外面，由 PC 按需喂给单片机。

这里踩过一个坑：原理图 PDF 里的 LCD 接线和实物不一样，照着 PDF 配一直是黑屏，后来按实物改成 SCL=PB13、SDA=PB15、RES=PB7、DC=PD7、CS=PD4 才正常。图纸对不等于板子对。

怎么跑起来的

1. 先把 PC 那条路走通

我没有一上来就写单片机代码，而是先在 PC 上把整条推理链路用纯 C 跑通，跟 llama2.c 原版对比数值。

原因是想清楚一件事：如果同时引入"新量化格式 + 新硬件 + 新存储"，出了问题根本不知道怪谁。 所以每步只引入一个变量。

上游的 runq.c 里其实藏着 bug：FFN 的 w2 是 [64,172] 形状，172 不能被 64 整除，原版量化时最后 44 个元素根本没被处理；而且每行的起点会落在量化组内部，scale 用错了。但因为矩阵元素总数能整除分组，文件能正常生成、程序也能跑，只是结果是错的 —— 相对 FP32 的 Logits 误差高达 31.6%。

修完之后降到 1.13%，Top-1 一致率从 47.9% 涨到 98.96%。修的就是按激活组边界、权重组边界和行尾三者拆段。

2. KV 缓存只能量化

原本 64 个 token 的 KV 缓存要 80 KB，比整个 SRAM 还大。改成 INT8，每 8 个元素共用一个 scale，压到 30 KB，代价是误差再涨一点点（还能接受）。

3. 权重靠"流式读取"

模型不在片内 Flash，所以每次算一层都要通过 model_read() 去要数据。整个推理过程没有 malloc，全是固定大小数组 + 静态断言。一次前向位置大概要把 278 KB 的权重过一遍。

4. 分词、采样、解码也在 MCU 里

这一步做完才是完整的闭环。PC 只发一句 UTF-8 原文，剩下的 BPE 分词、贪心选 token、UTF-8 拼接（一个汉字可能被拆在多个 byte token 里）全在单片机完成。

顺手做了一些保护：输入最多 128 字节、上下文最多 64 个位置（到顶就停，不回绕）、权重读超时 1.5 秒就中止、推理期间串口一样能响应 PING 和取消。中断服务程序里只收字节，绝不跑推理。

屏幕上也实时显示出来了：

生成的 token 是 407, 261, 378, 432，跟 PC 上离线跑上游参考的结果逐 ID 一致。串口错误 0、CRC 错误 0。

资源占用（实测）：

项目 占用
Flash 155.59 KB / 256 KB
SRAM（静态数据 + 栈） 46.97 KB / 64 KB
推理时最高栈水位 1056 B

说到速度就比较尴尬了

首输出 84 秒，4 个 token 一共 211 秒，大概 0.019 token/s。

但这个数字没什么参考价值：权重是走 115200 串口喂的，光把 278 KB 传一遍就要几十秒，真正算的时间其实很短。等外挂的 W25Q64 Flash 到货、换成 SPI 读取，速度估计能好不少 —— 不过在那之前我不想拿它跟别的项目比性能。

明确做不到的

  • 它不是中文大模型。屏幕能显示中文，是因为字库支持；模型本身是英文故事模型，中文它并不"懂"。
  • 不是聊天。每次发送都重置上下文，只是独立地续写英文小故事。
  • 输出很短，就是 upon a time, 这种级别的续写。
  • 外挂 Flash 还没接，SPI 读取、掉电加载这些都还没验证。

后面想做

等 Flash 到货，把权重从串口搬到 SPI；再试试更长的上下文，还有真正的 EOS 停止。慢慢来吧。
